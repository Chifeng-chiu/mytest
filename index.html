組員 2 進度報告｜邱祺峰

樂活在地通｜長輩關懷 PWA（前後端分離版 & 線上展示版）

將原本的單檔 index.html 拆成「長輩端」與「佳儒後台」兩個前端，並加上零外部依賴的 Node.js 伺服器。資料統一保存至 data/db.json，兩個視窗透過 SSE 即時同步；同時保留 legacy/index.html 部署於 GitHub Pages 供直接操作體驗。

1. 雙入口功能設計（長輩端 vs. 佳儒後台）

👵 長輩端 elder.html (PWA)

  • 大字／特大字切換：固定於頁面上方並記住選擇（內文最小 22px，按鈕至少 64px 高）
  • 緊急求助 SOS：按下立即建立求助紀錄，後台同步跳出警報
  • 佳儒的叮嚀：查看提醒、speechSynthesis 語音朗讀、回報完成
  • 老友照片牆：上傳照片、按讚、語音介紹、參加老友湊咖
  • 健康步數：模擬計步、金幣獎勵、每日問答、兌換獎勵
  • 社區廣播站：里長廣播、共餐報名（36人）、接駁車預約（醫院線/市場線）

👩‍💼 佳儒後台 admin.html (管理端)

  • SOS 求助監控：查看待處理警報、位置與時間，按「📞 已聯繫並解除警報」結案
  • 提醒發布與追蹤：指定班級（如長青A班林阿公）、時間、類型，追蹤長輩回報進度
  • 社區廣播發布：新增里長廣播，長輩端 1~3 秒內即時收到
  • 名單管理：集中查看共餐名單、接駁車名單、老友湊咖名單
  • 一鍵重設 Demo：右上角按鈕呼叫 POST /api/reset 從 seed.json 還原初始狀態

2. 跨視窗即時同步與並排示範流程

⚡ 技術架構與離線佇列

  • 後端透過 Server-Sent Events (SSE) GET /api/events 即時推送完整狀態
  • 若 SSE 中斷，前端自動改用每 3 秒輪詢 GET /api/state
  • sw.js 快取 App Shell；離線時先顯示 localStorage 上次資料，修改排入離線佇列，恢復連線後自動補送
  • db.json 採「先寫暫存檔、再重新命名」原子寫入，避免檔案損毀

🖥️ 報告現場並排示範 6 步驟

  • 1. 執行 node server.js 啟動零依賴伺服器
  • 2. 左右並排開啟 elder.html 與 admin.html
  • 3. 長輩端按「緊急求助」→ 後台立即跳出 SOS 警報
  • 4. 後台按「📞 已聯繫並解除警報」→ 長輩端同步更新狀態
  • 5. 後台發布新提醒或里長廣播 → 長輩端 1 秒內即時顯示
  • 6. 按後台右上角「重設 Demo」→ 雙視窗瞬間回到初始資料

3. 專案目錄結構

長者APP/
├─ server.js                 # 零依賴 Node.js 伺服器：靜態檔案、REST API、SSE
├─ README-PWA.md
├─ data/
│  ├─ seed.json              # 示範資料母本；按「重設 Demo」時會從這裡還原
│  └─ db.json                # 目前運作中的資料；伺服器啟動後自動建立／載入
├─ public/
│  ├─ elder.html             # 長輩端（PWA）
│  ├─ admin.html             # 佳儒後台
│  ├─ manifest.json          # 長輩端 PWA manifest
│  ├─ sw.js                  # Service Worker（App Shell 快取）
│  ├─ css/styles.css         # 共用視覺樣式（暖米色背景、高對比色塊）
│  ├─ js/                    # api.js (快取/離線佇列/SSE)、elder.js、admin.js
│  └─ icons/                 # PWA 圖示
└─ legacy/                   # 原始單檔版本備份（目前已部署於 GitHub Pages 線上展示）

核心設計與功能亮點

📈 1. 遊戲化等級與經驗值進度

  • 首頁上方清楚顯示「溫馨客廳｜等級 1 新手長者」與經驗值進度條（如 0 / 120 經驗值 與金幣數量）

  • 內建互動式任務對話框，配備 10:00 倒數計時器與冷卻時間提示

  • 不用複雜選單，「點一下房間裡的傢俱，就能選款式」
  • 消耗累積的經驗值/金幣即可解鎖新傢俱與切換不同房間場景，支援 PWA manifest 安裝
